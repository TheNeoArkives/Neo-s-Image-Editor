
# 🖼️ Neo's Image Editor

A simple yet powerful image editor built with **Tkinter** and **Pillow (PIL)** in Python.  
Edit your images with ease using an intuitive GUI packed with essential features.

---

## ✨ Features

- 🖼️ **Open & Save Images** (supports PNG, JPEG, BMP, TIFF, and more)
- 🎨 **Basic Transformations**  
  - Grayscale  
  - Blur  
  - Rotate  
  - Resize  
  - Flip  
- 💡 **Image Enhancements**  
  - Brightness  
  - Contrast  
  - Sharpness  
- 🎭 **Filters**
- ✂️ **Cropping**
- 🔍 **Zoom In/Out**
- 📊 **Status Bar**
- ⚙️ **Error Handling & Threaded Operations** for better responsiveness

---

## 🚀 Getting Started

### Requirements

- Python 3.x  
- [`Pillow`](https://pypi.org/project/Pillow/)  
- `Tkinter` (comes with most Python installations)

### Install Dependencies

```bash
pip install pillow
```

---

## 🧑‍💻 How to Use

1. **Open the project folder** in your code editor.
2. Run the script (e.g., `python main.py`) — it opens a GUI.
3. Upload an image and start editing!
4. Save your final masterpiece in any format: **PNG, JPEG, BMP, TIFF**.

---

## 📁 Supported Formats

- PNG
- JPEG / JPG
- BMP
- TIFF
